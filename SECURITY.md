# Reporting a security vulnerability

Use [NomadFi's private vulnerability reporting channel](https://github.com/arieltyson/nomadfi-accessibility/security/advisories/new). Include the affected app or website version, a description of the impact, and reproduction steps using invented data. Omit real account numbers, balances, transactions, receipts, secrets, and unrelated personal information.

GitHub and the maintainer can access a private report. It is not a public issue. There is no guaranteed response time. Non-sensitive questions and accessibility barriers belong in the public issue form.
